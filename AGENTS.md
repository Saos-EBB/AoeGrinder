# Regeln für Agents

## Grundregel: NIE Pay-to-win
- Der Shop läuft ausschließlich über im Spiel erspielten Staub.
- Keine Echtgeld-Option, die stärker macht. Niemals.
- Kommt je eine bezahlte Option dazu, dann nur Kosmetik.

- Lies zuerst [docs/overview.md](docs/overview.md), dann [docs/handoff.md](docs/handoff.md).
- **`docs/overview.md` („Was ist los“):** Wird nur im docmode bearbeitet. Soll die Datei geändert werden: docmode anschalten, die Datei nach den Regeln des Skills `docmode` aktualisieren, docmode wieder ausschalten. Sonst bleibt der Modus aus.
- **`CHANGELOG.md`:** Jede sichtbare Änderung bekommt im selben Commit eine Zeile, neueste oben.
