# Regeln für Agents

- Lies zuerst [docs/overview.md](docs/overview.md), dann [docs/handoff.md](docs/handoff.md).
- **`docs/overview.md` („Was ist los“) ist immer im docmode:** Sie wird nach den Regeln des Skills `docmode` gepflegt und läuft dauerhaft. Ändert sich etwas Übersichts-relevantes (neues Modul, neuer Befehl, neue Besonderheit), zieht derselbe Commit die Datei nach. Sie bleibt kurz, zeigt den aktuellen Stand statt eines Verlaufs, jede Aussage hat eine Quelle und jeder Link muss existieren.
- **`CHANGELOG.md`:** Jede sichtbare Änderung bekommt im selben Commit eine Zeile, neueste oben.
