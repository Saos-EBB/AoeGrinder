# Frost Grind

Ein Browser-Game, das ich aus Spaß mache. Es verbindet alles, was ich an Games mag: AoE-Grinden wie der Mage in WoW Classic, dazu Roguelike-Runs mit Karten, Runen und Relikten, Speedrun-Gedanken und ein Modus, in dem einfach immer mehr Mobs kommen, bis nichts mehr geht.

**Komplett in Arbeit.** Der Look ist noch ziemlich raw. Gerade probiere ich aus, was Sinn macht und was sich gut anfühlt: welche Spells, welches Balancing und so weiter. Es kann sich also jederzeit alles ändern, und die meisten Zahlen sind Platzhalter.

## Starten
```
npm install
npm run dev
```
Dann die angezeigte URL im Browser öffnen. `npm run build` erzeugt eine einzelne `dist/index.html`.

## Was drin ist
- **Figuren:** Kapuzenmagier, Eis-, Feuer- und Arkan-Skelett, Skelett-Krieger (Modus Real Men)
- **Mob-Modi:** Packs auf der Karte oder Belagerung: Mobs vom Rand, ohne Obergrenze, immer mehr
- **Runs:** Level-Karten, Runen, Relikte, Mods und eine lokale Rangliste
- **5 Zonen** und 15 Waffen
